# Jobs-On-Demand Flywheel Kit

Five agents you install in your own GoHighLevel account, with your AI assistant doing most of the work beside you:

| Agent | What it does |
|---|---|
| Booking | Answers every new message and form lead in seconds, and alerts your sales team to call. |
| Follow-up | Follows up every quiet lead and every sent quote until the homeowner books or decides. |
| Reviews | Checks in after every finished job and asks happy customers for an honest review. |
| Ads | Turns the jobs your crews do into new ads and moves ad spend by your rules. |
| Data | Shows which ad or source turned into signed jobs, on one weekly scoreboard. |

**You need:** GoHighLevel, and an AI assistant that works on your computer: Claude Code (recommended), the Claude desktop app, or Codex. `INSTALL-GUIDE.md` lists everything and walks you through the install in 7 days.

## Install it (pick one)

**1. Claude Code, one command (easiest).** In Claude Code, type:

```
/plugin marketplace add akashpunnoose0211/jobs-on-demand-flywheel-kit
/plugin install jobs-on-demand-flywheel-kit@jobs-on-demand-flywheel-kit
```

Then say **"start the flywheel kit"**.

**2. Paste a link into Claude or Codex.** Paste this, and say "save these as skills":

```
https://github.com/akashpunnoose0211/jobs-on-demand-flywheel-kit/tree/v1.1.0/skills
```

Then say **"start the flywheel kit"**.

**3. Download the folder.** Click the green **Code** button, then **Download ZIP** (or use the zip from your thank-you page). Unzip it, open the folder in Claude Code or Codex, and say **"start"**. The folder already holds your AI's instructions.

## What's inside
- `START-HERE.md`: what the kit is, and the five rules every agent follows.
- `INSTALL-GUIDE.md`: the software you need, and what to install each day.
- `MY-NUMBERS.md`: your business facts. Your AI fills it in with you on day 1.
- `setup/`: beginner guides for Claude Code and GoHighLevel, and for getting your texting approved the first time.
- `agents/`: one file per agent, `01` to `05`, with every step, message and test.
- `skills/`: the same guides as installable skills, one per agent, plus `flywheel-kit-start`.

Nothing here sends a message, spends money or goes live by itself. Every agent is built in draft and tested on your own phone, and nothing reaches a customer until you say yes.
